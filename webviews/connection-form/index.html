Nova Conexão de Banco de Dados

Configure os parâmetros JDBC para compilação e preenchimento de relatórios JasperReports. As senhas são armazenadas exclusivamente no cofre seguro do sistema operacional (SecretStorage).

Identificador amigável exibido na barra lateral e na Status Bar.
Selecione o arquivo .jar externo (ex: mssql-jdbc.jar, mysql-connector-j.jar).
Se preenchida, terá prioridade sobre a combinação automática de Host/Porta/Database.
Armazenada com criptografia via VS Code SecretStorage.
